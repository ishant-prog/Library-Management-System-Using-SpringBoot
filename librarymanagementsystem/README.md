# 📚 Library Management System

A Library Management System developed using Spring Boot that helps manage books, authors, publishers, and categories. It provides a simple interface for performing CRUD operations and managing library records efficiently.

## 🚀 Features

- User authentication and login
- Add, update, delete, and view books
- Manage authors
- Manage publishers
- Manage categories
- Search books
- Responsive web interface using Thymeleaf
- MySQL database integration

## 🛠️ Tech Stack

- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA
- Spring Security
- Thymeleaf
- MySQL
- Maven
- HTML
- CSS
- Bootstrap

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/ishant-prog/Library-Management-System.git
```

2. Open the project in IntelliJ IDEA or Eclipse.

3. Create a MySQL database.

4. Update database credentials in:

```
src/main/resources/application.properties
```

5. Run the project using:

```bash
mvn spring-boot:run
```

6. Open your browser:

```
http://localhost:8080
```
